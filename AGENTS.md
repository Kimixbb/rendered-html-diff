## IMPORTANT
- Use red/green TDD. Write the tests first, confirm that the tests fail before you implement the change that gets them to pass.
- Reuse or make slight changes and then reuse code if possible to prevent code duplication.
- Use less em-dashes during writing tasks.
- Make comments on codes. Make sure they are both helpful for future maintanence and easy / comprehensive to be read by beginner programmers and serve as educational guide for them.
- Be precise rather than brief in git messages. Include details.
